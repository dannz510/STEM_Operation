# STEM Command Center

## Overview
The STEM Command Center is a web application designed to manage assets, loan tickets, member information, and operational shifts within the Châu Thành STEM organization. This application leverages React and TypeScript for a robust and type-safe development experience.

## Features
- **Asset Management**: View, edit, and manage assets within the inventory.
- **Loan Ticket System**: Create and manage loan tickets for assets.
- **Member Management**: Edit and maintain member information and merit points.
- **Shift Management**: Add and manage operational shifts.
- **Incident Reporting**: Report incidents related to assets.
- **Google Workspace Integration**: Seamlessly integrate with Google Workspace functionalities.

## Getting Started

### Prerequisites
- Node.js (version 14 or higher)
- npm (Node Package Manager)

### Installation
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd stem-command-center
   ```
3. Install the dependencies:
   ```
   npm install
   ```

### Running the Application
To start the development server, run:
```
npm run dev
```
The application will be available at `http://localhost:3000`.

### Building for Production
To create a production build, run:
```
npm run build
```
The build files will be generated in the `dist` directory.

## File Structure
- `src/`: Contains all source code files.
- `public/`: Contains static assets.
- `package.json`: Lists dependencies and scripts.
- `tsconfig.json`: TypeScript configuration.
- `vite.config.ts`: Vite configuration for the project.
