# Security Policy

## Supported Versions

The following versions of **STEM.Lab / OS** are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | :white_check_mark: |
| 5.0.x   | :x:                |
| 4.0.x   | :white_check_mark: |
| < 4.0   | :x:                |

## Reporting a Vulnerability

If you discover any security vulnerabilities within the Lab Operation System, please follow the procedure below to report them securely:

- **Reporting Channel:** Create a private security advisory via [GitHub Security Advisories](https://github.com/dannz510/STEM_Operation/security/advisories/new) or contact the system administrator directly (Maintainer: `dannz510`).
- **Information Required:**
  - Detailed description of the vulnerability (e.g., Supabase/Firebase permission flaws, XSS, environment variable leaks).
  - Step-by-step reproduction instructions (Steps to reproduce).
  - Potential impact assessment on operational systems.
- **Response Timeline:** You will receive an initial verification response within **48 hours**, along with remediation progress updates if the vulnerability is validated.
